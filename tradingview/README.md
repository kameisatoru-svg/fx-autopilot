# TradingView 連携

戦略の価格レベルを TradingView のチャートに描く Pine スクリプト置き場。

## strategy_levels.pine

その日のセットアップ（エントリーゾーン・ターゲット・無効化ライン）を TradingView に
水平線として表示し、ゾーン進入や無効化でアラートを出すインジケーター。

### 入力項目
- **押し目買いゾーン**：ゾーン上限／下限（塗りつぶし表示）
- **ターゲット／補助**：ターゲット1・2、補助ライン（0で非表示）
- **無効化ライン**：割れたらセットアップ消滅

### 使い方
1. TradingView でチャートを開く（対象ペア・時間足）。
2. 下部の「**Pineエディタ**」を開く。
3. `strategy_levels.pine` の中身を貼り付け → 「**チャートに追加**」。
4. インジケーターの**歯車（設定）→ 入力**で、その日のレベルを入力する。
5. アラートは、チャート右上の「アラート」→ 条件にこのインジケーターの
   「買いゾーン進入」「無効化ライン割れ」「ターゲット1到達」を選ぶ。

### メモ
- 初期値は **2026-06-28 USD/JPY 4H の押し目買いセットアップ**（Golden Pocket 160.35–160.54 等）。
- 売りセットアップで使う場合は、ゾーンを戻り売りゾーンに読み替えて値を差し替える
  （または別名で複製してペア別・方向別に保存）。
- 数値は `strategies/日付.md` の「コア判定／注目価格帯」から転記する想定。
- 将来的に「`strategies/日付.md` → .pine 自動生成」までつなげる予定。
