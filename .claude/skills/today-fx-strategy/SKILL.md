# 今日のFX戦略 生成スキル

朝の相場解説動画（のぶ塾）の文字起こしを入力に、ユーザーの手法に沿って
「今日のFX戦略」を作成する。動画は相場観・テーマ・注目ポイントの**情報源**であり、
最終的なトレード判断は下記の手法（トレンドフォロー）に従う。

## 対象通貨ペア（ドル円中心）
1. USD/JPY（ドル円）
2. GBP/JPY（ポンド円）
3. AUD/JPY（オージー円）
4. EUR/JPY（ユーロ円）
5. EUR/USD（ユーロドル）
6. AUD/USD（オージードル）

動画で言及のないペアは「言及なし／様子見」とし、無理にシナリオを作らない。

---

## 手法の中核（判断の前提）

出典: `docs/strategy/entry_ver12.pdf`（100億円トレーダー「4つの鉄板エントリーパターン」）

1. **トレンドフォロー専用**。逆張りはしない。動画が逆張り的見解を述べても、
   戦略は順張り前提で組む。
2. **マルチタイムフレーム（MTF）**
   - 大きな流れ＝日足・4時間足／中くらい＝4時間足・1時間足／小さな＝1時間足・15分足
   - トレード足（執行）は基本 **1時間足**（1時間足レベルの押し目を拾う時のみ15分足）
3. **ダウ理論でトレンド判定**
   - 上昇＝安値切り上げ＋高値更新／下降＝高値切り下げ＋安値更新
   - **「トレンド終了」≠「トレンド転換」**：高値切り下げ/安値切り上げ"だけ"は終了。
     更新を伴って初めて転換。
   - ダウの高安は「1つ下の時間軸の20SMAの波の高安」を基準にする。
4. **移動平均線**：各時間軸に20SMA。MAの傾きと、レートがMAのどちら側かで優位性を補強。
5. **エントリー大原則**：大きな流れの方向を見極め、トレード足（1時間足）が
   その方向に**合致する瞬間**（押し目買い／戻り売りの完成・トレンド転換）で入る。
6. **4つの鉄板パターン**（狙う波の時間軸が違うだけで考え方は同じ）
   - ① **4時間足レベルの押し目・戻り目**（最重要・実トレードの約8割）
   - ② 1時間足レベルの押し目・戻り目
   - ③ 日足レベルの押し目・戻り目
   - ④ 4時間足レベルのトレンド転換
7. **「戦争状態」は回避**：上位足と下位足で売り買いの思惑が逆（押し目買い勢力と
   戻り売り勢力が交錯）の局面はノートレード。レートが伸びず狩られやすい。
8. **損切り**：直近の押し目（安値切り上げ）／戻り高値の少し外側。
   「1時間足レベルの損切り幅で上位足のリワードを狙う」＝リスクリワード重視。
9. **保有・利確**：優位性が崩れるまで保有（デイトレだが2〜3日保有も可）。
   週末持ち越しはしない。
   ※PDFは損切り/利確の数値ルールを外部記事に委ねており詳細未記載。
     当面は「押し安値/戻り高値の外＋RR重視」を既定とし、ユーザー独自ルールで上書き可。

## 出力テンプレート「今日のFX戦略」

```
# 今日のFX戦略 — {YYYY-MM-DD}（出典: のぶ塾 朝動画）

## ① 相場環境認識
- 全体テーマ / マクロ（米株・金利・要人発言・地政学など、動画の要点）
- 本日の注意イベント（指標・要人発言・介入リスク 等）

## ② 通貨ペア別シナリオ
（対象6ペアのうち、動画で言及 or 手法的に優位性のあるものを記載）

### USD/JPY
- 環境認識: 日足/4時間足の方向観（動画＋手法のMTF視点）
- 狙う鉄板パターン: ①〜④のどれか
- メインシナリオ: 方向 / エントリー条件（どの足のトレンド転換・押し目か） / 想定エントリー帯 / 損切り目安 / 狙う方向
- サブシナリオ: （あれば）
- 戦争状態の注意: 避けるべき局面（上位足と下位足が逆の時など）

（GBP/JPY, AUD/JPY, EUR/JPY, EUR/USD, AUD/USD も同様）

## ③ 注目価格帯・ライン
- 動画で言及された節目・水平線・直近高安（取れる範囲で）

## ④ リスク管理
- 推奨リスク%（FX Autopilot アプリのモード連動: 通常2% / 攻撃3% / 守備1% / 停止0%）
- 当日のトレード可否（戦争状態・重要指標前などはノートレード推奨を明記）

## ⑤ 手法チェックリスト（エントリー前の確認）
- [ ] 大きな流れ（日足・4時間足）の方向は明確か
- [ ] トレード足（1時間足）が大きな流れに合致しているか
- [ ] ダウのトレンド転換/押し目戻り目が確定しているか（終了と混同していないか）
- [ ] 戦争状態（上位足と下位足の思惑が逆）ではないか
- [ ] 損切り位置とRRは妥当か（1時間足の損切り幅で上位足のリワード）

> ※本戦略は具体的な売買助言ではなく、手法に沿った当日の方針メモ（たたき台）。
>   実エントリーは自分のチャート分析で最終判断すること。
```

## 手順

1. ユーザーが貼り付けた文字起こし（のぶ塾の朝動画）を読む。
2. 文字起こしから次を抽出する:
   - 全体相場観・テーマ・マクロ材料・注意イベント
   - 各通貨ペアへの言及（方向観、注目価格帯、強弱）
3. 抽出した相場観を**手法のフレーム**に通す:
   - 各ペアについて、大きな流れ（日足・4時間足）の方向観を整理
   - 4つの鉄板パターンのどれが狙えそうかを当てはめる
   - 戦争状態になりそうな局面（上位足と下位足が逆）には注意を付す
4. 出力テンプレートに沿って「今日のFX戦略」を生成する。
5. 文字起こしに情報がない項目は「言及なし」と明示し、推測で断定しない。

## 注意・原則

- 動画の見解と手法（トレンドフォロー）が食い違う場合は**手法を優先**する。
- 価格帯など文字起こしに数値がない場合は無理に作らず「動画で言及なし」とする。
- 自動字幕由来の誤変換は文脈で補正する。
- これは投資助言ではなく、当日のトレード方針のたたき台である旨を必ず添える。
