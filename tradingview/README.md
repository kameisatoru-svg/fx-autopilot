# TradingView 連携

戦略の価格レベルを TradingView のチャートに描く Pine スクリプト置き場。

## strategy_levels.pine

`strategies/日付.md` の「注目価格帯・ライン」を TradingView に水平線として表示し、
節目到達でアラートを出すインジケーター。

### 使い方
1. TradingView でチャートを開く（対象ペア・時間足）。
2. 下部の「**Pineエディタ**」を開く。
3. `strategy_levels.pine` の中身を貼り付け → 「**チャートに追加**」。
4. インジケーターの**歯車（設定）→ 入力**で、その日のレベルを入力する。
5. アラートを使う場合は、チャート右上の「アラート」→ 条件にこのインジケーターの
   「戻り売りゾーン到達」「下値ターゲット到達」を選ぶ。

### メモ
- まずは USD/JPY 用の数値を初期値にしてあります。ペアごとに値を差し替えて使う、
  または別名で複製してペア別に保存してください。
- 将来的に「`strategies/日付.md` → .pine 自動生成」までつなげる予定。
